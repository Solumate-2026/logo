# Solumate V2 - Dark / Light Logo Kit

Both themes use the same S monogram, eight connection terminals and outlined Space Grotesk wordmark. The light version uses deeper cyan to remain visible on pale surfaces; the dark version uses brighter cyan and near-white lettering.

## Choose a Theme

- Use `light/` on white and other light backgrounds.
- Use `dark/` on navy and other dark backgrounds.
- Choose the logo according to the surface it is placed on, not just the operating-system theme.

## Files in Each Theme Folder

| Filename | PNG size | Background | Intended use |
| --- | --- | --- | --- |
| `logo.svg` / `logo.png` | 3200 x 832 | Transparent | Horizontal logo for headers and general branding |
| `icon.svg` / `icon.png` | 2048 x 2048 | Transparent | Standalone brand symbol |
| `logo-mono.svg` / `logo-mono.png` | 3200 x 832 | Transparent | Single-color horizontal logo |
| `logo-on-background.svg` / `logo-on-background.png` | 3200 x 1200 | Solid theme background | Ready-to-use banner with the logo |
| `app-icon.svg` / `app-icon.png` | 1024 x 1024 | Solid theme background | Square app-icon artwork |

SVG files are scalable, self-contained vector masters. Text is outlined, and the files do not require a font installation, external images or network access. The S-shaped cutout in transparent exports is genuinely transparent.

App-icon exports have an opaque square background. Rounded corners in the preview are presentation-only; the exported artwork has no rounded or transparent corners.
